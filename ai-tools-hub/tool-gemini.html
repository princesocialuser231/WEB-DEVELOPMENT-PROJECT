Gemini

Open Gemini

What it does

Gemini is Google’s AI assistant. It works with Google apps and can create images and read long files.

Use cases

  • Summarise a long PDF
  • Plan a study schedule
  • Generate an image for a poster

How to use it

  1. Open gemini.google.com with your Google account
  2. Type a task or upload a file
  3. Refine the answer with follow-ups

Pros and cons

ProCon
Fits well if you already use Google appsAnswers can be wrong, so verify facts
