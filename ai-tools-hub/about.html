About AI Tools Hub

Why we built it

There are hundreds of AI tools, and it is hard to know which one fits a task. This site groups tools by the job they do and explains how to use each one.

What you will find

  • Free tools with a page for each tool.
  • Paid tools and AI plans that come with a SIM recharge.
  • A comparison table.

How it is built

Plain HTML and one CSS file, using what we learned in CS103 labs: semantic tags, lists, tables, forms, Flexbox, Grid and media queries.
