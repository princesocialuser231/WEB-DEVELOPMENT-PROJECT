Open Canva

What it does

Canva is a drag-and-drop design editor with templates and AI features for images and layouts.

Use cases

  • Make a poster for a college event
  • Design social media posts
  • Build a presentation from a template

How to use it

  1. Sign in at canva.com
  2. Pick a template or start from a prompt
  3. Edit text and images, then download
