GitHub Copilot

Open GitHub Copilot

What it does

Copilot suggests code as you type in editors like VS Code and has a chat panel for questions.

Use cases

  • Autocomplete repeated code
  • Ask what a function does
  • Generate comments or tests

How to use it

  1. Sign in to GitHub and apply for the student pack if eligible
  2. Install the Copilot extension in VS Code
  3. Start typing or open Copilot chat
